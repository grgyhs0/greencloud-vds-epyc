## VDS 和普通 VPS 差在哪

差在 CPU 分配方式上。绿云的产品线大致分三层：Budget KVM 用共享节点上的 Intel 或 EPYC 处理器，多个用户分一颗物理核心；EPYC NVMe VDS 则是独享物理核心（dedicated cores），官网明确这一档没有邻居争抢（no CPU contention）的问题，存储也升级到 NVMe 4.0。

这个差异对什么人重要？如果你的负载是持续的——MySQL 查询压力大的站点、频繁编译、数据处理任务——共享节点上 CPU 被邻居拖慢时，你会明显感觉到卡顿，VDS 就是为这种场景准备的。反过来，一个日访客几百的 WordPress，99% 的时间 CPU 占用不到 5%，买 VDS 属于花钱买了个用不上的参数。

还有一点经常被忽略：绿云的 ToS 规定，**连续 30 分钟以上占满 100% vCPU 会被自动限速甚至强行关机**。这条对共享型套餐影响更大——哪怕你买了高配 Budget KVM，想长期跑满 CPU 做转码或分布式计算也会触发限制。真正要长期吃满核心，VDS 独享核心是更合适的选择。

## 机房怎么选：同一价格，流量能差 4 倍

这是很多测评文章没讲透的一点：绿云促销套餐的价格虽然在各机房基本一致，**流量配额差距很大**。同样 $25/年，东京 IIJ、软银、香港 DC1、新加坡 DC2 都只给 750GB 月流量，英国考文垂给 3TB——4 倍差距。8GB 内存档更明显，东京是 $68/年，香港、新加坡、英国则是 $20/季（折合 $80/年，但按季付费）。

选择逻辑可以简化成两条：

1. **在意大陆访问延迟** → 东京（IIJ 或软银）和香港 DC1 优先。但注意，这些促销套餐的页面并没有明确承诺大陆三网优化，IIJ 和软银还是两条不同线路，电信、联通、移动的去回程表现各不相同，最好先要测试 IP 实测。
2. **要大流量、不在意大陆优化** → 英国考文垂，同价位流量是亚洲机房的 4 倍。美国本土机房（芝加哥、杰克逊维尔、堪萨斯城等）也经常有货，适合面向北美用户的服务。

IPv6 也别忽略：东京和香港 DC1 分配 /64，新加坡 DC2 是 /112，如果你的应用依赖大量 IPv6 地址，这一条能直接帮你排除某个机房。

## FAQ

**绿云vds 支持 Windows 吗？**
EPYC VDS 系列本身是 Linux 机型。需要 Windows 得选专门的 Windows VPS 线（Hyper-V 虚拟化，默认开 RDP，1Gbps 端口，流量不限量），两个系列是分开购买的。

**$25/年 那个套餐是真的吗，有什么坑？**
真，2026 年 10 月的多机房补货里就是这个价，配置 1 核 EPYC Milan / 2GB / 25GB NVMe。坑有两个：750GB 月流量在亚洲机房算紧张，以及不可退款。另外 1GB 内存级别的机器建议部署完先建 1GB Swap（swappiness 设 10），避免 MySQL/PHP 进程 OOM 崩溃。

**抢到特价机之后能升级配置吗？**
促销套餐的性质是锁价锁配置的独立商品，不要默认它能原地升级。有扩容需求的话，常见的做法是再补一台更高配的机，把数据迁过去。

**10Gbps 端口是独享的吗？**
不是。10Gbps 是端口规格上限，实际带宽共享，且部分存储机型被限在 1Gbps。对带宽有硬性要求的要看清套餐页的具体标注。
